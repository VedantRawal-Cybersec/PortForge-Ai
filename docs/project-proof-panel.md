# PortForge AI product evidence

The platform is for **every user**, not a single owner's personal career or project list.

## Present behavior
- Skill, interview and project grading records are stored in the current browser's localStorage.
- The portfolio shows users only their own locally produced entries.
- Entries are AI-assisted feedback, not third-party verified certificates.
- Clearing browser data may permanently remove locally stored entries.

## Commercial roadmap
- Add authenticated user accounts with secure session management.
- Save artifacts, scoring provenance, and assessment history server-side with ownership RLS.
- Build revocable, signed evidence links for genuinely verified outputs.
- Support user-controlled profile visibility and portable exports.
- Never feature a person's private projects or identity as platform default data.
